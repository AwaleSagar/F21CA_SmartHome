# Smart_Home

## Local setup

Two files the application expects at runtime are intentionally **not** kept in
version control (see the repository `.gitignore`). Provide them locally before
running `CACTY.py`:

| File | How to obtain it |
| --- | --- |
| `SmartHome_Cacty/ngrok` | Download the Linux binary from <https://ngrok.com/download>, unzip it into `SmartHome_Cacty/` and `chmod +x ngrok`. |
| `SmartHome_Cacty/Lab1/sample_bot/calendarEvents/credentials.json` | Create an OAuth 2.0 *Desktop app* client in the Google Cloud console, enable the Google Calendar API, and download the client-secret JSON to this path. |

`token.pickle` in the same directory is generated on first run by
`setting_google_api.py` once you complete the OAuth consent flow — it is a
user credential and must never be committed.

`speech.mp3` is regenerated by the text-to-speech step on every run.
